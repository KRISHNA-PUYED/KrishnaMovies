# Krishna Cineverse - Poster Image Edition

Open index.html in your browser or use VS Code Live Server.

Files:
- index.html: application markup
- style.css: responsive styling
- app.js: 10 movie entries and three-per-page pagination

This no-token demo uses remote illustrative cinematic images from Unsplash. They are not verified official Bollywood film posters. Replace poster URLs in app.js with official/licensed image URLs if required.
